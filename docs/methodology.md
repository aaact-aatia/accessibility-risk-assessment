# Scoring methodology, version 1

This proof of concept reproduces the approved 49-criterion WCAG 2.1 Level A and AA source workbook. The source omits 4.1.1 Parsing; this is intentionally preserved. Scores support procurement decisions and are not conformance determinations.

Technical maximum: 90. Critical (8 × 3.8125), High (8 × 2), Medium (21 × 1.5), Low (12 × 1). Responses: Support and Not Applicable = full points; Partially Support = half; Does Not Support and Not Tested = zero. The source permits Not Applicable for criteria absent from the vendor report as well as genuinely inapplicable criteria. Governance maximum: 10, with question weights 3, 3, 2, 2; Yes and Not Required = full points, No = zero.

Overall = technical + governance. The source lists Low 90–100, Moderate 80–89.99, High 70–79.99, Critical below 70. The app applies these thresholds to the displayed two-decimal score because the source gives ranges but no risk formula. Incomplete assessments show provisional points without a final risk rating. This is an interface safeguard, not a change to point calculations.

The source sample totals 65.90625 technical + 10 governance = 75.90625 overall; counts 27 Support, 13 Partially Support, 3 Does Not Support, 4 Not Applicable, 2 Not Tested. Tests reproduce those values. Only canonical response labels are accepted; the source summary accepts plural aliases but scoring formulas do not.

No source workbook, contact details or sample vendor records are published.
